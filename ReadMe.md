# 🌐 Personal Portfolio Website

A responsive personal portfolio website built to showcase my **skills, projects, education, and professional experience**.

The website is designed as a single-page portfolio with smooth navigation, animations, interactive elements, and responsive styling for different screen sizes.

## 🔗 Live Demo

**[View Portfolio Website](https://udaysekharraju-biruduraju.github.io/Uday_Portfolio/)**

## 📸 Overview

This portfolio website contains the following sections:

* 🏠 **Home** – Introduction and social links
* 👨‍💻 **About Me** – Short introduction and professional summary
* 🛠️ **Skills & Abilities** – Technologies and tools
* 🎓 **Education** – Academic background
* 🚀 **Projects** – Selected projects with GitHub links
* 💼 **Experience** – Professional and internship experience
* 📞 **Contact** – Contact and social-media information

The sections and navigation are implemented directly in `index.html`.

## 💻 Run Locally

Since this is a static website, no backend server or database is required.

### 1. Clone the repository

```bash
git clone https://github.com/Uday-Sekhar-Raju-Biruduraju/Uday_Portfolio.git
```

### 2. Navigate to the project

```bash
cd Uday_Portfolio
```

### 3. Run the website

Open `index.html` directly in a browser.

Alternatively, if you are using **Visual Studio Code**, install the **Live Server** extension and select:

```text
Right Click → Open with Live Server
```

## 🌐 Deployment

The website can be deployed using **GitHub Pages**, since it is a static HTML/CSS/JavaScript project.

### GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings**.
3. Select **Pages**.
4. Select the deployment branch.
5. Save the configuration.
6. GitHub will generate the public website URL.
